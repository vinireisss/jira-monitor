# ⚡ Guia Ultra-Rápido

## 🎯 **Você Quer:**

### **Testar o Código?**
```bash
npm start
```

---

### **Atualizar a Versão Instalada?**
```bash
npm run build && ./install.sh
```

---

## 🔄 **Workflow Diário:**

```
1. Editar código
   ↓
2. npm start (testar)
   ↓
3. npm run build && ./install.sh (atualizar)
   ↓
4. ✅ Pronto!
```
