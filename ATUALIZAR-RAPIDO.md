## 📝 **O que cada comando faz:**

1. **`cd ~/dev/nu/jira-monitor`**  
   → Vai para a pasta do projeto (padrão: `/Users/seu-usuario/dev/nu/jira-monitor`)

2. **`git pull origin main`**  
   → Baixa as últimas alterações do GitHub

3. **`npm start`**  
   → Inicia o app atualizado

## ⚠️ **Deu erro?**

### Erro: "Your local changes would be overwritten"

```bash
git reset --hard origin/main
git pull origin main
```

### Erro: Dependências desatualizadas

```bash
npm install
```

### Erro: App não inicia

```bash
npm run clean
npm install
npm start
```
