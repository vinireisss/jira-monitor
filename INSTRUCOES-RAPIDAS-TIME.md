# 🚀 Jira Monitor - Comandos Rápidos para o Time

## 📦 Instalação (Executar UMA VEZ)

```bash
cd ~/dev/nu/jira-monitor
git pull origin main
./fix-aliases.sh
source ~/.zshrc
```

## ⚡ Comandos do Dia a Dia

### Abrir o app
```bash
j
```

### Atualizar para última versão
```bash
jira-update
```

### Reiniciar se travar
```bash
jira-restart
```
