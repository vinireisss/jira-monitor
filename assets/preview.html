📋 Próximos Passos:

1. Converter SVG → PNG (512x512):
Acesse: cloudconvert.com/svg-to-png
• Faça upload do arquivo icon.svg
• Configure tamanho: 512x512
• Baixe e salve como icon.png na pasta assets/
2. Converter PNG → ICNS (macOS):
Acesse: cloudconvert.com/png-to-icns
• Faça upload do icon.png
• Baixe e salve como icon.icns na pasta assets/
3. Rebuild do app:
Execute no terminal: npm run package
4. Testar:
Abra o app buildado e veja o novo ícone! 🎉
